Memeriksa server…

Satu video panjang, sepuluh klip yang layak diposting.

Tempel tautan YouTube atau unggah file video. ClipForge menandai momen paling kuat, memotongnya ke format vertikal, dan menggerakkan bingkai mengikuti pembicara.

Mendukung format youtube.com/watch, youtu.be, dan /shorts. Pratinjau gambar tidak tersedia di mode tautan sampai backend tersambung.

Letakkan file video di sini

MP4, MOV, WebM, atau MKV — file tetap di perangkat kamu.

Mode ini berjalan penuh di browser: durasi, pratinjau, dan bingkai klip diambil langsung dari file kamu.
